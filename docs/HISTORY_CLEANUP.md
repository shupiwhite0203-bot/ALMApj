# Git履歴軽量化の準備記録

2026-10-02、元リポジトリの全参照をGit bundleにバックアップし、検証したうえで隔離コピーを作成しました。そのコピーでgit-filter-repo 2.47.0を実行し、過去履歴から `.venv/`、`runs/`、`vendor/` を除外しました。

| 指標 | 元リポジトリ | 隔離した軽量化コピー |
| --- | ---: | ---: |
| オブジェクト容量（loose + pack） | 約190 MiB | 約83 KiB |
| HEADで追跡するファイル | 1,929 | 34 |

値はドキュメント改善の未コミット分を取り込む前の履歴についてのものです。軽量化後も11コミットの流れを保持していますが、コミットIDは変わります。

実行した履歴変換：

```text
git-filter-repo --path .venv/ --path runs/ --path vendor/ --invert-paths
```

元リポジトリとGitHubの履歴は変更していません。通常のコミット・pushでは、現在のツリーからファイルを外せても過去履歴の容量は減りません。

## 本番反映の手順

1. ローカルの未コミット変更と、最新のリモート状態を確認する。
2. 現在のソース・ドキュメント整備を軽量化コピーへ取り込む。
3. 軽量化コピーで構文・依存・推論の確認を行う。
4. 書き換え対象のブランチ・タグ、復元用バックアップを確認する。
5. 明示的な承認後、対象を限定したforce-with-leaseでGitHubの履歴を置き換える。

履歴を置き換えると、共有されたコミットURLや既存クローンに影響します。共同作業者は再クローンなどの対応が必要です。GitHub側のキャッシュや保持オブジェクトが即時に消えるとは保証できません。GitHubの共有URL自体は同じものを維持できます。
